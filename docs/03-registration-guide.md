# 03 — NISR Official Registration Guide (with Loom)

> 🎥 **Rule from the formative:** screen-record the ENTIRE registration with **Loom — not Zoom**. The recording must show the emails entered on the form clearly enough to confirm them on camera. This is how both the course and NISR verify the registration is genuinely yours. Submit the Loom link on Canvas alongside the team declaration.

## Step 0 — Before you open the form

- [ ] Team declared on Canvas (see [01-team-declaration.md](01-team-declaration.md)) — **declaration comes first**
- [x] Track chosen and noted
- [x] Team name decided
- [x] Both members' details at hand: **full name, email, phone, gender, department**
- [ ] Proof of student status file ready: **one file, ≤ 10 MB**, `jpg / jpeg / png / pdf / doc / docx` (e.g., ALU student ID or enrolment letter; scan to PDF if photo)

## Step 1 — Open the registration portal

NISR's registration link is published on [statistics.gov.rw](https://www.statistics.gov.rw) (Hackathon page) and their official socials. Only use links from NISR's official channels.

> 📞 NISR competitions contact (from previous editions): **competition@statistics.gov.rw** · Tel 0788 720 57. The 2026-specific page/posts go live around the 1 Sep 2026 launch — check the site's Hackathon section or their X/LinkedIn for the form link.

| University/College affiliation(s) | **African Leadership University** |
| Team name | Inyange Analytics |
| Team leader: name / email / phone / gender / department | Kevin Nizeyimana / kevin.nizeyimana@alu.edu / +250 788 123 456 / Male / Data Science |
| Full list of team members incl. gender (leader included) | Kevin Nizeyimana (Male), Laura (Female) |
| Proof of student status | upload the prepared file |

Double-check **email spellings** — the Loom must show them clearly, so type carefully and slowly.

## Step 3 — Record with Loom

1. Install/verify the Loom Chrome extension or desktop app.
2. Start a **screen recording** (camera bubble optional) and show:
   - the blank form → each field being filled → the file upload → the final **Submit** click,
   - a final pause on the confirmation screen (screenshot it too).
3. Keep the whole flow in **one continuous take** — no cuts.
4. Title it `NISR 2026 Hackathon Registration — <Team Name>` and copy the share link.

## Step 4 — After submission

- [ ] Save the confirmation email / screenshot
- [ ] Paste the Loom link into [docs/05-submission-checklist.md](05-submission-checklist.md)
- [ ] Submit Loom link + Canvas declaration on Canvas before the course deadline (earlier than 20 Oct 2026)

## Common pitfalls

- ❌ Recording with Zoom → not accepted; **Loom only**
- ❌ Emails illegible in the recording → re-record; zoom your browser to ~110–125% while filling email fields
- ❌ Choosing "Infographic" instead of "2026 Hackathon"
- ❌ File > 10 MB → compress the ID scan
- ❌ Registering before the Canvas declaration
